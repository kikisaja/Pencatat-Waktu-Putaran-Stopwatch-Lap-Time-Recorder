# Proyek 81: Lap Time Recorder (Pencatat Waktu Putaran Stopwatch)

Proyek ini adalah aplikasi web stopwatch interaktif yang dilengkapi fitur pencetak waktu putaran (*lap time*), kalkulasi durasi antar-lap, serta deteksi otomatis putaran tercepat (*fastest lap*) dan terlambat (*slowest lap*). Dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript**, sangat cocok untuk pembelajaran manipulasi `setInterval`, penanganan `Date.now()`, dan *array mapping* di tingkat SMK/pemula.
